# Backed

Back the people who make it. A marketplace where fans buy music, film and art straight from creators.

Website: React and Vite, published on GitHub Pages. Database, login and file storage: Supabase. Payments and downloads: one Supabase Edge Function in `supabase/functions/api`. Payments: Paystack.

Start with `SETUP.md`. Database setup is the single file `supabase/setup.sql`. Admin tasks are in `docs/admin-runbook.md`, email in `docs/email-setup.md`, films and currencies in `docs/film-and-art.md`.
